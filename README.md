# 🎬 Video Unlocker Pro — با حالت دابل‌واچ (تماشای دونفره همزمان)

اکستنشن کروم برای کنترل پیشرفتهٔ پخش ویدیو + **قابلیت جدید «دابل‌واچ»**: دو نفر هرکدام در تب/مرورگر خودش انیمه می‌بیند، یک **کد اشتراک** به دوستش می‌دهد و پخش/مکث/جابه‌جایی زمان بین هر دو نفر همگام (sync) می‌ماند. کنترل پخش فقط دست **میزبان** است.

## ✨ قابلیت‌ها
- حذف قفل/پاپ‌آپ و فعال‌سازی کنترل‌های پخش player
- پنل شناور کنترل سرعت، صدا، نوار زمان و تمام‌صفحه
- 👥 **دابل‌واچ**: ساخت اتاق با کد ۶ رقمی + لینک اشتراک + رمز اختیاری
- همگام‌سازی play / pause / seek بین دو نفر + رفع drift هر ۱۰ ثانیه
- ورود خودکار مهمان از طریق لینک (تب جدا با hash کد اتاق)
- اتصال مجدد خودکار در صورت قطع شدن + heartbeat

## 📦 نصب اکستنشن
1. این مخزن را Clone یا Download ZIP کنید.
2. در مرورگر (کروم/اج) به `chrome://extensions` بروید.
3. **Developer mode** را روشن کنید → **Load unpacked** → پوشهٔ پروژه را انتخاب کنید.

## ☁️ راه‌اندازی سرور همگام‌سازی (Cloudflare Worker — رایگان)
برای اینکه دو مرورگر مختلف بتوانند به هم وصل شوند، به یک سرور رلهٔ WebSocket نیاز دارید. فایل [`worker.js`](./worker.js) همین کار را روی Cloudflare Workers انجام می‌دهد (رایگان، بدون سرور شخصی):

1. در [dash.cloudflare.com](https://dash.cloudflare.com) → **Workers & Pages** → **Create** → **Worker** یک Worker تازه بسازید.
   (یا با CLI: `npm i -g wrangler && wrangler init dw-sync` و کپی محتوای worker.js در index.js سپس `wrangler deploy`)
2. کل محتوای فایل `worker.js` را در ادیتور جایگزین کنید و **Deploy** بزنید.
3. آدرس حاصل (مثل `https://dw-sync.yourname.workers.dev`) را در فایل `double-watch.js` وارد کنید:
   ```js
   const SYNC_SERVER_URL = 'https://dw-sync.yourname.workers.dev';
   ```
4. در `chrome://extensions` دکمهٔ Reload اکستنشن را بزنید.

## 🎮 طرز استفادهٔ دابل‌واچ
1. میزبان صفحهٔ انیمه را باز و (در صورت نیاز) با اکستنشن آن‌لاک می‌کند.
2. در پنل اکستنشن روی دکمهٔ **👥 دابل‌واچ** کلیک کنید → **🔗 ایجاد لینک**.
3. لینک/کد ۶ رقمی را برای دوستتان بفرستید (با 🔒 می‌توانید رمز اتاق بگذارید).
4. دوستتان لینک را باز می‌کند → صفحهٔ Join → دکمهٔ ورود → در تب او همان انیمه باز و **خودکار** به اتاق متصل می‌شود.
5. حالا هر دو همزمان می‌بینند؛ **فقط میزبان** Play/Pause/Seek می‌کند و سمت مهمان اعمال می‌شود. دکمهٔ 🔄 همگام‌سازی خطاها را رفع می‌کند.
6. **🗂️ تب جدید**: بعد از اتصال، دکمهٔ «باز کردن صفحهٔ ویدیو در تب جدید» در بخش دابل‌واچ ظاهر می‌شود؛ با آن همان انیمه در یک تب جدا باز شده و خودکار به اتاق وصل می‌شود (مثلاً برای تمام‌صفحه کردن هر پنجره جداگانه).

> نکته: اگر دوستتان روی سیستم دیگری است، او لینک را باز می‌کند؛ اگر روی همین مرورگر است، دکمهٔ 🗂️ تب جدید را بزنید.

> نکته: مهمان باید همان ویدیو را در سایت پخش کند تا جریان همگام شود؛ اگر سایت لاگین/VIP بخواهد، هر دو نفر باید دسترسی خودشان را داشته باشند.

## ⚖️ سلب مسئولیت
این پروژه صرفاً برای آموزش و استفادهٔ شخصی است. دور زدن قفل‌های پرداختی/VIP سرویس‌های استریم، نقض شرایط استفادهٔ آن‌هاست و مسئولیت آن کاملاً بر عهدهٔ کاربر است. از این ابزار فقط برای محتوایی استفاده کنید که حق پخش آن را دارید.

## 📁 ساختار فایل‌ها
| فایل | نقش |
|---|---|
| `manifest.json` | تعریف MV3 اکستنشن |
| `content.js` | دکمهٔ فعال‌سازی (ISOLATED world) |
| `background.js` | Service worker — تزریق main.js |
| `main.js` | پنل کنترل + منطق پلیر دابل‌واچ (MAIN world) |
| `double-watch.js` | WebSocket کلاینت، اتاق‌ها، UI دابل‌واچ، صفحهٔ Join (ISOLATED world) |
| `worker.js` | سرور رلهٔ Cloudflare Worker |
